# Типы карт

В игре четыре типа карт: **штабы**, **техника**, **взводы** и **приказы**.

## Штаб

Ключевая карта колоды, в единственном экземпляре. Стоит в углу поля.
Его уничтожение заканчивает бой.

Характеристики штаба: **огневая мощь**, **прочность**, **прирост ресурсов**.
Стоимости вывода у штаба нет — он на поле с самого начала.

Штаб атакует любую обнаруженную незамаскированную цель на всём поле и вражеский
штаб напрямую. **Ответного урона не получает и сам не контратакует.**

### Четыре типа штабов

| Тип | Профиль |
| --- | --- |
| **Учебный** | Стартовый, доступен сразу. Уровень I |
| **Ударный** | Повышенная огневая мощь |
| **Сводный** | Повышенная прочность |
| **Тыловой** | Повышенный прирост ресурсов |

Уровни штабов: **I**, **IV** и **VIII**. Учебные бывают только первого уровня.
Штабы 8-го уровня в среднем сильнее по всем характеристикам и имеют более
мощные способности.

Тип и нация штаба включают **зависимые свойства** карт — см. ниже.

## Техника

Основной боевой тип. Разыгрывается на плацдарм, перемещается по полю, атакует.

Характеристики: **стоимость вывода**, **огневая мощь**, **прочность**,
**прирост ресурсов**, **класс**.

Пять классов подробно разобраны в [04. Классы техники](04-классы-техники.md).

## Взводы

Пехотные подразделения, поддерживающие штаб. Стоят в зоне поддержки,
**не перемещаются** и не занимают клеток поля.

### Два вида

| Вид | Что делает |
| --- | --- |
| **Атакующий** | Когда штаб атакует, прибавляет свою поддержку к его огневой мощи и получает столько же урона |
| **Защитный** | Когда штаб атакован, поглощает урон в пределах своей поддержки |

### Пять специализаций

Разведчики, Связисты, Артиллеристы, Медики, Инженеры.

Функционально специализации **не различаются**. Их единственное назначение —
ограничить состав: **одновременно можно держать до пяти взводов, по одному
каждой специализации**. Если разыграть второй взвод той же специализации,
предыдущий уходит в потери.

## Приказы

Карты одноразового действия. Срабатывают мгновенно при розыгрыше и сразу уходят
в потери.

Особенности:

- Действуют **по всему полю**, независимо от расположения.
- **Игнорируют «Маскировку» и «Охранение»** — эти свойства от приказов не защищают.
- Единственные ограничения — хватает ли ресурсов и есть ли подходящая цель.

Внимательно смотрите на цель приказа: одни играются на свой штаб, другие — на
вражеский, третьи — на технику. Если цели нет, приказ разыграть нельзя.

Отдельно стоит помнить про приказы с массовым эффектом: в их тексте цель не
указана, поэтому их можно сыграть даже впустую — просто чтобы сбросить карту.

## Свойства карт

Часть карт имеет дополнительные свойства, описывающие исключения из общих правил.
Они делятся на четыре группы.

### Ключевые свойства

Имеют собственные названия и указаны прямо на карте.

| Свойство | Действие |
| --- | --- |
| **Арьергард** | Карта разыгрывается без уплаты ресурсов, если она последняя в руке |
| **Блиц** | Вместо ресурсов можно заплатить столько же случайных карт из колоды, отправив их в потери |
| **Конвейер** | В колоду можно взять больше трёх копий: количество = уровень штаба + 3 |
| **Маскировка** | Карту не могут атаковать вражеский штаб и САУ, даже если она обнаружена |
| **Охранение** | Находясь на плацдарме, карта принимает на себя весь урон по штабу |
| **Прикрытие** | Карту нельзя контратаковать |
| **Подкрепления** | При розыгрыше карты игрок берёт дополнительную карту |

### Зависимые свойства

Работают только под штабом определённой **нации** и/или **типа**.
В бою игрок видит лишь те свойства, которые действуют с его текущим штабом;
полный список свойств карты был доступен в редакторе колод.

Именно эти свойства заставляют собирать колоду вокруг конкретного штаба:
одна и та же карта под «своим» штабом может быть вдвое сильнее.

### Активируемые свойства

Используются **один раз за ход вместо атаки**. Обозначались значком с двумя
стрелками.

### Оплачиваемые свойства

Можно использовать **несколько раз за ход**, каждый раз оплачивая ресурсами.
На карте показывались канистрой с числом — стоимостью одного применения.
