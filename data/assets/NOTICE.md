# О правах на изображения

Файлы в этом каталоге — **оригинальные арты карт и иллюстрации World of Tanks
Generals**, скачанные с `wiki.wgcdn.co` (официальная вики Wargaming).

Они являются интеллектуальной собственностью **Wargaming.net** и приведены здесь
для изучения и восстановления правил игры, прекратившей существование в 2016 году.

## Если вы делаете на этой основе свою игру

Изображения нужно заменить. Код к этому подготовлен: путь к арту формируется
в **одном месте** — функция `cardArtUrl` в `apps/web/src/data.ts`:

```ts
export function cardArtUrl(card: CardDef | undefined): string | null {
  if (!card?.imageFile) return null;
  return `/art/cards/${card.imageFile}`;
}
```

Чтобы подключить свой набор изображений, достаточно поменять эту функцию и
положить файлы в соответствующий каталог. Остальной код изменений не потребует.

Сами игровые данные (характеристики карт, тексты способностей) — это факты
о правилах игры, восстановленные из открытых источников; список источников
приведён в [docs/12-источники.md](../../docs/12-источники.md).
