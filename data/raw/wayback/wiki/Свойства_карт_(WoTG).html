Некоторые карты обладают свойствами, которые описывают дополнительные правила для этих карт.

Свойства карт бывают следующих типов:

  • Ключевые
  • Зависимые
  • Активируемые
  • Оплачиваемые

Ключевые свойства

Ключевые свойства карт имеют собственные названия. Эти названия указаны в описании карт.

250px
Свойство Описание
Арьергард Карту можно разыграть без уплаты ресурсов, если карта последняя в руке.
Блиц За розыгрыш карты можно заплатить не ресурсами, а таким же количеством случайных карт из колоды, переместив эти карты в потери.
Конвейер Можно добавить в колоду более трёх копий этой карты.

Количество копий = уровень штаба + 3.

Маскировка Карта не может быть атакована САУ и штабом противника, даже если карта обнаружена.
Охранение Карта принимает на себя атаки по штабу, если находится рядом со штабом.
Прикрытие Карту нельзя контратаковать.
Подкрепления При розыгрыше карты игрок получает в руку дополнительную карту из колоды.


Зависимые свойства

Свойства некоторых карт зависят от принадлежности штаба к определённому типу и/или нации. Чтобы зависимые свойства работали, штаб должен быть того типа и/или нации, которые указаны перед текстом зависимого свойства:

250px
Символ Описание
Свойство работает для ударного штаба.
Свойство работает для тылового штаба.
Свойство работает для сводного штаба.
Флаг СССР Свойство работает для штаба СССР.
Флаг Германии Свойство работает для штаба Германии.
Флаг США Свойство работает для штаба США.


Во время боя карты отображают только те свойства, условиям которых удовлетворяет штаб. Полную информацию о картах можно получить в редакторе колод.




Активируемые свойства

250px

Некоторые карты имеют дополнительное свойство, которое можно использовать один раз за ход вместо атаки.


Активируемое свойство отмечается значком с двумя стрелками.
















Оплачиваемые свойства

250px

Некоторые карты имеют дополнительное свойство, которое можно использовать несколько раз за ход. Для этого нужно заплатить количество ресурсов, равное числу на канистре.


Оплачиваемое свойство отмечается значком — канистрой с числом.
