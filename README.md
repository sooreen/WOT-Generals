# World of Tanks Generals — реконструкция

Документация и играбельная реализация браузерной карточной игры
**World of Tanks Generals** (Wargaming, 2015–2016). Игра закрыта, клиент утрачен;
здесь собрано всё, что удалось восстановить из открытых источников, и на этой
основе построена работающая игра против компьютера.

## Что внутри

| | |
| --- | --- |
| **Документация** | [`docs/`](docs/) — правила, бой, фракции, глоссарий, экономика |
| **База карт** | 154 карты в [`data/cards.json`](data/cards.json), плюс CSV для таблиц |
| **Изображения** | 153 оригинальных арта карт и 31 иллюстрация в [`data/assets/`](data/assets/) |
| **Движок правил** | [`packages/engine`](packages/engine) — чистый TypeScript, 42 теста |
| **ИИ-оппоненты** | [`packages/ai`](packages/ai) — 4 уровня сложности + режим нейросети |
| **Игра** | [`apps/web`](apps/web) — браузерный клиент, [`apps/server`](apps/server) — сервер |

Начать чтение стоит с [обзора игры](docs/00-обзор.md), а для написания своего
кода — с [модели реализации](docs/11-модель-реализации.md).

## Быстрый запуск

### Через Docker (рекомендуется для сервера)

```bash
cp .env.example .env      # при желании впишите ANTHROPIC_API_KEY
docker compose up -d --build
```

Игра будет доступна на `http://<адрес-сервера>:8080`.

### Локально

```bash
pnpm install
pnpm --filter @wotg/web build
pnpm start                 # сервер на http://localhost:8080
```

Для разработки клиента с горячей перезагрузкой:

```bash
pnpm --filter @wotg/server dev   # в одном терминале
pnpm --filter @wotg/web dev      # в другом, откроется на :5173
```

## Оппоненты

Четыре программных уровня работают **прямо в браузере**, без сети и без ключей:

| Уровень | Как играет | Задержка хода |
| --- | --- | --- |
| **Новобранец** | Случайные разумные ходы | мгновенно |
| **Сержант** | Жадная оценка на один полуход | мгновенно |
| **Офицер** | Поиск на несколько полуходов | ~15 мс |
| **Генерал** | Поиск методом Монте-Карло | ~370 мс |

Проверено самоигрой (по 6 партий на пару, стороны чередуются):
Сержант обыгрывает Новобранца в 83 % партий, Офицер Сержанта — в 83 %,
Генерал Офицера — в 67 %, Генерал Новобранца — в 100 %.

### Пятый режим: нейросеть

Если задать `ANTHROPIC_API_KEY`, в меню появляется оппонент **«Нейросеть»**.
Схема намеренно гибридная:

- движок **на сервере** строит список легальных ходов;
- модель выбирает из него **номер хода**;
- ответ проверяется движком.

Поэтому модель физически не может сходить не по правилам, ключ не покидает
сервер, а при любом сбое (нет ключа, таймаут, лимит частоты) ход делает
программный «Офицер» — партия не прерывается.

Настройки — в [`.env.example`](.env.example).

## Как пересобрать данные

Все данные собираются воспроизводимыми скриптами:

```bash
pnpm scrape:wiki       # 240 страниц раздела Card: + страницы правил
pnpm scrape:classes    # класс техники для карт без описания — из энциклопедии WoT
pnpm scrape:wayback    # удалённые страницы вики и официальные гайды из архива
pnpm scrape:assets     # арты карт с wiki.wgcdn.co
pnpm data:parse        # викитекст → cards.json / cards.csv / research-tree.json
pnpm data:abilities    # тексты способностей → исполняемый DSL
pnpm docs:build        # машинные разделы документации
```

Скрипты кешируют ответы на диск и не бьют по чужим серверам при повторном запуске.

## Проверка

```bash
pnpm test                            # 42 теста движка
npx tsx tools/bench/selfplay.mts 10  # самоигра: растёт ли сила с уровнем
npx tsx tools/bench/latency.mts      # время принятия решения
node tools/e2e/play.mjs              # сквозной прогон в браузере (нужен запущенный сервер)
```

## Честно о полноте

- **154 карты** — столько задокументировано на вики Wargaming. Сама Wargaming
  заявляла «более 200»; разница — карты, которые на вики не завели.
- **153 арта из 154**: изображение карты `Pz35(t)` на вики так и не загрузили.
- **84,8 % способностей** переведены в исполняемый вид, из них 59,3 % — полностью.
  Остальные сохранены текстом; карта с такой способностью работает по базовым
  характеристикам. Полный список — в [источниках](docs/12-источники.md).
- Клиент оригинальной игры, его анимации и звук **не сохранились нигде** и
  восстановлению не подлежат.

## Правовая заметка

Арты карт и названия принадлежат Wargaming.net и используются здесь для изучения
правил закрытой игры. При публикации собственной игры их необходимо заменить —
см. [`data/assets/NOTICE.md`](data/assets/NOTICE.md), подмена затрагивает одну функцию.
